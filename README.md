# Треки

**Музыка по ссылке — для Mac.** Скопируй ссылку на трек, альбом или плейлист, открой «Треки» и нажми «Скачать». Трек с обложкой, названием, артистом и альбомом появится в папке «Музыка → Скачанное» и в приложении Музыка.

Работает со ссылками Spotify, Apple Music, Яндекс Музыки, YouTube Music, YouTube и SoundCloud. А можно просто написать «артист — песня».

**[⬇ Скачать последнюю версию (.dmg)](https://github.com/MelonDirector/treki/releases/latest)** · Mac на Apple Silicon (M1 и новее), macOS 14+

---

## Установка

1. Скачай `Treki-<версия>.dmg`, открой и перетащи «Треки» в «Программы».
2. При первом запуске macOS скажет, что не может проверить разработчика (приложение не из App Store). Открой **Системные настройки → Конфиденциальность и безопасность** и нажми **«Всё равно открыть»**.
   Если кнопки нет: `xattr -dr com.apple.quarantine /Applications/Треки.app`

Ставить больше ничего не нужно — всё нужное уже внутри.

## Возможности

- Ссылка из буфера подставляется сама, можно и перетащить её на окно.
- Альбомы и плейлисты — галочками выбираешь, что скачать.
- Если трек нашёлся не тот (ремикс, кавер) — «Не тот трек?» покажет другие варианты.
- M4A или MP3, своя папка, отдельные папки для альбомов.
- Встроенный плеер — послушать сразу после скачивания.
- Сама подсказывает, что делать с Яндекс Музыкой из-за границы (российский прокси) и в России с VPN.
- Проверяет обновления раз в сутки — один запрос к GitHub без каких-либо данных о тебе.

## Как это работает

Площадки по ссылке отдают только данные о треке: название, артиста, длительность, обложку. Звук «Треки» находят на YouTube Music, сверяют название и длительность и скачивают (качество примерно 128 kbps AAC).

**Только для личного прослушивания.** Для роликов и коммерческих проектов нужна лицензионная музыка.

## Обновление

Скачай новый `.dmg` и перетащи приложение в «Программы» с заменой — настройки и история сохранятся.
